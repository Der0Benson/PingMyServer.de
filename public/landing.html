Ein Check, vom Ziel bis zur Meldung.

Ein beispielhafter Ablauf · keine Live-Daten

  1. Eine Verbindung. Dein Ziel.

    Aus dem Netzwerk wird ein einzelner Check.

  2. Eine Anfrage geht raus.

    PingMyServer ruft deine Website über HTTP auf.

  3. Die Antwort kommt zurück.

    Status und Antwortzeit werden gemessen und im Verlauf gespeichert.

  4. Beim nächsten Check: keine Antwort.

    Ein Timeout wird erkannt und als Vorfall festgehalten.

  5. Du erfährst davon.

    Die Meldung geht an deine eingerichteten Kanäle.

HTTP GET → 200 OK · 184 ms. Beim nächsten Check: TIMEOUT → Meldung per E-Mail, Discord, Slack oder Webhook.
